# Целочисленная 2D-геометрия

Полные реализации на C++20, компилируемые примеры и тесты. Имена находятся
в `namespace geometry`. Нужен GCC или Clang с поддержкой `__int128_t`.

Координаты входных точек: `|x|, |y| <= 10^9`; число вершин многоугольника:
не больше `10^6`. Разности хранятся в `long long`, промежуточные произведения
и площади — в `Wide` (`__int128_t`). Предикаты точные, без `EPS`.
Для печати `Wide` используйте `ToString`; расстояния возвращаются приближённо
как `long double`.

| Заголовок | Операции | Пример |
|---|---|---|
| [point.h](point.h) | Скалярное и векторное произведения, ориентация, квадрат расстояния, поворот на 90°, нормализация направления | [Квадрат по стороне](point_example.cpp) |
| [segments.h](segments.h) | Точка на отрезке, пересечение отрезков, точное пересечение прямых, расстояния | [Прямые и отрезки](segments_example.cpp) |
| [rectangles.h](rectangles.h) | Ограничивающий прямоугольник, пересечение, принадлежность, площадь, периметр | [Прямоугольники](rectangles_example.cpp) |
| [polygons.h](polygons.h) | Удвоенная площадь, положение точки, выпуклая оболочка | [Многоугольники](polygons_example.cpp) |

Подключите нужный заголовок: зависимости подключаются автоматически.
Для переноса листингов в один файл порядок такой: `point.h`, `segments.h`,
затем `rectangles.h` и/или `polygons.h`; локальные `#include` и `#pragma once`
удаляются. Подробное описание алгоритмов и контрактов включено в `trd.typ`.

## Контракты

- `OnSegment` и `SegmentsIntersect` включают касания и вырожденные отрезки.
- `IntersectLines` различает единственное пересечение, параллельность,
  совпадение и вырожденную пару точек. Для единственного пересечения
  возвращает точные дроби `x_num / den`, `y_num / den`, где `den > 0`.
- `IntegerPoint` проверяет целочисленность и диапазон `long long`.
  Полученный результат может выйти за пределы входного ограничения `10^9`;
  перед дальнейшими геометрическими вычислениями проверьте его величину.
- `Intersect` для прямоугольников сохраняет касание как прямоугольник
  нулевой площади. Отсутствие пересечения обозначается `nullopt`.
- `LocatePoint` возвращает `Outside`, `Boundary` или `Inside`. Вершины
  простого многоугольника должны идти по границе, без самопересечений.
- `ConvexHull` возвращает вершины против часовой стрелки, начиная с
  лексикографически минимальной, без повторения первой вершины в конце
  и без промежуточных коллинеарных точек. Для коллинеарного набора остаются
  два крайних конца; пустой набор и одна точка поддерживаются.

## Проверка

Из корня репозитория:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
typst compile --root . trd.typ build/trd.pdf
```

Четыре теста `geometry_*` проверяют вырождения и большие координаты,
исчерпывающе перебирают малые конфигурации отрезков и прямоугольников,
сравнивают оболочку и принадлежность точки с независимыми реализациями.
Проверки не зависят от `assert` и работают в Release.
