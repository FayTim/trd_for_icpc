## Компоненты сильной связности (SCC)

`FindScc(graph)` разбивает ориентированный граф на компоненты сильной
связности: внутри каждой компоненты любые две вершины достижимы друг из друга.
Используется итеративный алгоритм Косарайю без рекурсии, время и память —
`O(n + m)` для `n` вершин и `m` рёбер.

- `graph[v]` содержит номера вершин, в которые ведут рёбра из `v`.
  Все номера должны принадлежать `[0, n)`, а `n` не должно превышать `INT_MAX`.
  Эти условия проверяет вызывающий код. Петли и повторные рёбра допустимы.
- `SccResult::count` — число компонент; `component[v]` — номер компоненты
  вершины `v` в диапазоне `[0, count)`. Входной граф не изменяется.
- Номера компонент следуют топологическому порядку: для ребра `u -> v`
  между разными компонентами `component[u] < component[v]`.
  Порядок несравнимых компонент не фиксирован. На эту ориентацию номеров
  опирается реализация [TwoSat](../two_sat/README.md).
- Для пустого графа возвращаются `count == 0` и пустой `component`.

[Описание](description.typ) включается в общий документ Typst.
[Пример](example.cpp) компилируется в CI вместе с [тестами](test.cpp).
[Заголовок](scc.h) можно подключить или скопировать перед решением задачи.

Запуск примера из корня репозитория:

```sh
mkdir -p build
c++ -std=c++20 algorithms/scc/example.cpp -o build/scc_example
./build/scc_example
```

Пример выводит `3` и `0 0 1 2 2`: компоненты `{0, 1}`, `{2}`, `{3, 4}`
соединены в цепочку именно в таком порядке.
