## Компоненты сильной связности (SCC)

`FindScc(graph)` — итеративный Косарайю: `O(n + m)` времени и памяти
для `n` вершин и `m` рёбер. Вход — списки смежности, вершины `0..n-1`.

Результат: `count` — число компонент, `component[v]` — номер компоненты вершины.
Нумерация топологическая: для ребра `u -> v` между разными компонентами
`component[u] < component[v]`.
