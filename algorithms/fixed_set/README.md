## FixedSet

Статическое множество 32-битных `int` на основе двухуровневого идеального
хеширования (FKS). Требуется C++20.

- `Initialize(numbers)` заменяет набор ключей; дубликаты игнорируются.
- `Contains(number)` проверяет принадлежность за `O(1)` в худшем случае.
- По умолчанию множество пустое. `Initialize({})` очищает его.
- Построение занимает ожидаемое `O(m)` время для `m` входных чисел;
  готовое множество использует `O(n)` памяти для `n` различных ключей.

[Описание и устройство](description.typ) включаются в общий документ Typst.
[Пример использования](example.cpp) компилируется вместе с тестами в CI.
[Заголовок](fixed_set.h) можно подключить или целиком скопировать в посылку.

Запуск примера из корня репозитория:

```sh
mkdir -p build
c++ -std=c++20 algorithms/fixed_set/example.cpp -o build/fixed_set_example
./build/fixed_set_example
```

Повторная инициализация полностью заменяет множество. Отдельных операций
добавления и удаления нет; входной вектор хранить после вызова не нужно.
