## FixedSet

Статическое множество целых чисел на основе двухуровневого идеального
хеширования (FKS). Подходит, когда набор ключей известен заранее, а затем
нужно много раз проверять принадлежность числа этому набору.

### Интерфейс и ограничения

- `FixedSet()` создаёт пустое множество.
- `Initialize(const std::vector<int>& numbers)` строит множество из всех
  различных чисел в `numbers`. Дубликаты игнорируются, входной вектор
  не изменяется и не должен храниться после вызова.
- `Contains(int number) const` возвращает `true`, если число есть в множестве.
  До первой инициализации и после `Initialize({})` возвращает `false`.
- Повторный вызов `Initialize` полностью заменяет предыдущее множество.
  Отдельных операций добавления и удаления нет: при изменении набора нужна
  новая инициализация.
- Поддерживается весь диапазон 32-битного `int`, включая отрицательные числа,
  `INT_MIN` и `INT_MAX`. Требуется C++20 (`std::span` и designated initializers).

Для `m` входных чисел и `n` различных ключей построение занимает ожидаемое
`O(m)` время; готовое множество использует `O(n)` памяти. `Contains` работает
за `O(1)` в худшем случае. Построение рандомизировано: хеш-функции выбираются
заново при каждом вызове, поэтому время и внутреннее размещение могут отличаться.

### Пример использования

Подключите заголовок из корня репозитория. Для посылки в проверяющую систему
можно скопировать `fixed_set.h` целиком (вместе с его стандартными подключениями)
перед `main`.

```cpp
#include <iostream>
#include <vector>

#include "algorithms/fixed_set/fixed_set.h"

int main() {
  FixedSet set;
  set.Initialize({7, -3, 7, 0});

  std::cout << std::boolalpha;
  std::cout << set.Contains(7) << '\n';   // true
  std::cout << set.Contains(42) << '\n';  // false
  std::cout << set.Contains(-3) << '\n';  // true

  set.Initialize({42});
  std::cout << set.Contains(7) << '\n';   // false
  std::cout << set.Contains(42) << '\n';  // true

  set.Initialize({});
  std::cout << set.Contains(42) << '\n';  // false
}
```

Сохраните пример как `example.cpp` и выполните из корня репозитория:

```sh
c++ -std=c++20 -I. example.cpp -o example
./example
```

### Как устроено

Сначала удаляются дубликаты. Первый уровень распределяет `n` ключей по `n`
корзинам; хеш-функция подбирается так, чтобы сумма квадратов размеров корзин
не превышала `4n`. Для каждой непустой корзины из `k` ключей выделяется
таблица из `k²` ячеек и подбирается собственная хеш-функция без коллизий.
Поиск вычисляет два индекса и сравнивает ключ в выбранной ячейке с запросом.
Пустая ячейка представлена через `std::optional<int>`, поэтому специальное
«запрещённое» значение ключа не требуется.
