## TwoSat

Решает 2-SAT: конъюнкцию дизъюнкций из двух булевых литералов. Поддерживает
импликации, фиксацию литерала и условие «истинен ровно один из двух».
Использует [SCC](../scc/README.md); произвольные булевы формулы не принимает.

### Использование

1. Создайте `TwoSat solver(n)` для переменных с индексами `0..n-1`.
2. Получите **литералы** через `TwoSat::Literal(i)` для `x_i` и
   `TwoSat::Literal(i, false)` для `!x_i`. Их номера — `2*i` и `2*i+1`;
   отрицание литерала `a` — `a ^ 1`.
3. Передавайте в ограничения номера литералов, а не индексы переменных:
   `AddOr(a, b)` добавляет `a || b`, `AddImplication(a, b)` — `a -> b`
   вместе с контрапозицией, `ForceTrue(a)` требует истинности `a`,
   `AddExactlyOne(a, b)` требует истинности ровно одного из `a` и `b`.
4. Вызовите `Solve()`. `std::nullopt` означает отсутствие решения;
   иначе `(*answer)[i]` — значение **переменной** `x_i`. При `n == 0`
   результат содержит пустой вектор: проверяйте `has_value()`, а не размер.

`Solve()` не меняет ограничения: его можно вызывать повторно и добавлять
условия между вызовами. При нескольких решениях возвращается любое.
`AddExactlyOne(a, a)` противоречиво; `AddExactlyOne(a, a ^ 1)` всегда истинно.

Число переменных должно быть в диапазоне `0..INT_MAX/2`, каждый передаваемый
литерал — в диапазоне `0..2*n-1`. Аргументы не проверяются; доступная память
может ограничивать размер раньше. Добавление одного условия занимает
амортизированное `O(1)` время, каждый `Solve()` — `O(n + m)` времени и памяти,
где `m` — число добавленных условий. В репозитории используется C++20.

Готовый [пример](example.cpp) печатает `false true`, затем `false`:

```sh
mkdir -p build
c++ -std=c++20 algorithms/two_sat/example.cpp -o build/two_sat_example
./build/two_sat_example
```

Для посылки одним файлом скопируйте сначала `scc.h`, затем `two_sat.h` перед
`main` вместе со стандартными подключениями. Удалите из копии `two_sat.h`
относительное подключение `#include "../scc/scc.h"`.

Описание для PDF находится в [description.typ](description.typ); оно читает
реализацию и пример из исходных файлов. Тесты проверяют все таблицы истинности
помощников, повторные решения и случайные формулы сравнением с полным перебором.
