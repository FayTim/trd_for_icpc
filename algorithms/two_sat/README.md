## TwoSat

2-SAT на основе [SCC](../scc/README.md). Добавление условия — амортизированное `O(1)`,
`Solve()` — `O(n + m)` времени и памяти для `n` переменных и `m` условий.

`Literal(i)` кодирует `x_i` как `2*i`, `Literal(i, false)` — `!x_i` как `2*i+1`.
Методы принимают номера литералов; отрицание `a` — `a ^ 1`.
`AddAtMostOne(a, b)` запрещает оба истинных литерала, но допускает оба ложных.
`Solve()` возвращает `optional<vector<bool>>` со значениями переменных
или `nullopt`, если решения нет. При `n == 0` решение — пустой вектор.
