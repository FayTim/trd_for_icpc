## CompressCoordinates

Сжатие координат: заменяет различные целые числа индексами `0..k-1`
в порядке возрастания. Равные значения получают одинаковый индекс;
порядок элементов исходного вектора сохраняется.

```cpp
const auto [to, from, compressed] = CompressCoordinates({50, -10, 50, 20});
// from:       {-10, 20, 50}
// compressed: {2, 0, 2, 1}
// to.at(20) == 1; from.at(2) == 50
```

Подключите [compress_coordinates.h](compress_coordinates.h). Возвращается
кортеж из отображения `to` (координата → индекс), вектора `from` (индекс →
координата) и вектора `compressed` (индексы всех входных элементов).
Входной вектор не изменяется. Пустой вход даёт три пустых контейнера.

Сохраняются порядок и равенство координат, но не расстояния между ними.
В `to` есть только входные координаты; используйте `at` для известных ключей
или `find`/`contains` для проверки наличия. Порядок обхода `to` не определён.

Для `n` входных чисел ожидаемое время — `O(n log n)`, дополнительная память —
`O(n)`. Из-за `std::unordered_map` худшее время может достигать `O(n²)`.
Поддерживается весь диапазон `int`. Сам заголовок требует C++17 или новее;
репозиторий собирает алгоритмы в режиме C++20.

[Описание для общего документа](description.typ) и [компилируемый пример](example.cpp)
лежат рядом с реализацией. Запуск примера из корня репозитория:

```sh
mkdir -p build
c++ -std=c++20 algorithms/compress_coordinates/example.cpp -o build/compress_coordinates_example
./build/compress_coordinates_example
```
